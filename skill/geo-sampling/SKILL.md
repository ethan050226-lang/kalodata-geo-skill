# GEO 采样 Skill / GEO Sampling Skill

## 默认交付

每次运行交付「飞书云空间看板预览链接＋简短报告」。运行Agent负责检查并复用已有飞书发布连接和私有配置、上传共享版、实测在线筛选及分页后返回链接；不能只把HTML附件发出就视为完成。运行 Skill 取数需要 Answerbit 品牌级只读 Key，由运行者安全提供或复用已安全配置的有效 Key；同事查看已生成的飞书看板，只需具备相应飞书访问权限，无需提供该 Key，也无需各自配置发布权限。用户要求公司内分享时，由运行Agent按已获准范围配置公司内只读，首次具体文件权限变更仍按[飞书交付规程](references/feishu-preview.md)确认。只生成本地文件、只有附件或在线交互失败时，明确写「免下载交付未完成」及处理人、下一步；HTML下载只作备用，不用下载后可交互冒充在线可用。

## 集中运行与统一入口

默认采用「中央环境执行本仓库工具＋统一 Agent 接收需求和推送」。统一入口可由项目管理员创建的 Agent 承担，名称与真实身份放私有配置，不绑定到公开 Skill。运营自己的 Agent 可作为获批的查询入口，不独立保存数据源密钥、重复取数或发布。安装 Skill 不等于中央服务、消息通道或调度器已接通。

- 统一入口确认运营国家、时间、时区和接收位置；中央任务只接受管理员批准的用户与国家映射，自报国家不能扩权。
- 仅订阅或查看结果时登记需求/返回获准的已验收版本，不触发 refresh；用户要求真实刷新或已启用计划到期时才提交中央执行请求。
- 中央环境复用已有只读连接、安全凭证和发布状态；同一品牌、窗口、题库及口径的兼容请求串行合并取数，再从同批私有快照裁剪并重算各国结果。不能循环调用各国 refresh 冒充一次取数。
- 首次接入、换环境或连接变更时，先列清权限与运行环境缺项、处理人、证据时间及审批状态，再安排真实运行。企业审批项先报告，不自动申请；检查未知不当作缺失，也不沿用另一应用的检查结论。
- 定时任务继续暂停。先完成一次真实「题库→Answerbit→国家裁剪→自检→飞书预览与权限→目标投递」验收；通过仅代表可申请启用，仍须用户另行明确要求恢复，不能验收后自动开。

中央环境、权限核对、能力边界与验收顺序统一见[集中执行与国家推送](references/scheduled-delivery.md)。单次分析仍可复用现有执行入口，不因此另建后台服务。

## 启动确认

用户主动运行时，一次收集以下信息；本次对话已明确的不要重复问。更新Skill后先核对当前交付要求及旧运行参数：本次已明确要求发布时，不沿用旧轮次的“暂不发布”或擅自加`--local-only`；用户当前仍明确禁止发布时先说明冲突，不静默覆盖。

1. **运营国家**：询问负责哪些国家，可多选。历史配置只作候选，请用户确认沿用或调整；不按语言、IP或采样网络地区猜。
2. **只读 Key**：真实取数由中央运行者在隐藏输入或获批环境安全配置仅覆盖 Kalodata 的品牌级只读 Key；已有安全配置检查后复用，不要求聊天明文提交。运营仅订阅、查询已验收结果或查看链接时不索要 Key，也不将中央密钥复制到其个人 Agent。告知预计耗时，按实际任务量和限流更新；首次真实运行缺少获准国家范围或可用 Key 时暂停真实取数及后续发布；已有已校验批次仅补发布按执行入口处理。离线复盘指定快照时无需 Key。
3. **题库只读连接**：先按[连接检查与复用](references/feishu-connection.md)检查当前运行环境的既有工具、应用及获批身份，复用已有只读连接并实读最新版。已有连接可用时不重复索要授权；失败须区分应用权限、用户登录、文件权限及工具问题，再按指引处理，不先让用户反复扫码或申请权限。
4. **推送需求**：已有暂停的定时任务保持暂停，更新Skill、修权限、单次运行或补发布都不能恢复任务。询问是否定时、频率、时间和接收位置；推荐每周一北京时间上午11:30，用户确认后只保存待验收订阅。已有计划展示后确认沿用或调整，单次分析不建订阅；单次完整验收通过后仍须用户明确要求才启用或恢复。具体按[集中执行与国家推送](references/scheduled-delivery.md)。

## 一次性题库接入与缺项提示

安装及每次运行先按[连接检查与复用](references/feishu-connection.md)复用公司已批准的工具、应用、读取身份及私有题库配置，不重建应用、不借用其他账号、不复制个人令牌。权限属于应用或账号，不随Skill转移；同一获批应用可在授权范围内复用，换Agent或环境仍须实读核验。题库结构、完整国家页及修订一致性全部通过后才继续Answerbit，不停在preflight，也不把历史成功当作本次成功。应用连接默认bot，已获批用户连接可用私有GEO_FEISHU_BANK_IDENTITY=user沿用；不静默切换身份。

面向用户只列「当前问题、谁来处理、下一步」，不要将配置变量、权限代码或程序库名列成要用户提供的三项资料，也不要称“第一阻断”。按实际失败分开说明：

| 当前问题 | 谁来处理、下一步 |
| --- | --- |
| 尚未找到 Kalodata 品牌 ID | Agent在Key就绪后先查获批私有配置；确实缺少时才请项目管理员安全补齐。已有值不重复索要，不写入公开Skill。 |
| 当前 Agent 还不能读取飞书题库 | 按连接指引区分应用权限、用户授权、文件阅读权限与网络。应用缺权限时给出当前应用的官方开通入口及最小只读项；免审仍先确认，确需企业审批再报告办理，不反复个人登录。文件访问不足才请用户提供题库可阅读权限，不要求编辑或管理权限。开通后必须实读验证，不能只看页面成功。 |
| 当前 Agent 缺少读取 Excel 的程序组件 | 由Agent检查现有可用环境，按项目依赖及获准方式处理；不要求用户提供或手动安装程序库。受环境限制时说明需运行平台管理员处理，未处理前不声称已修复。 |

技术权限名称、错误码和环境排查信息仅放在管理员详情中；正文先说明影响和处理人，不粘贴密钥、资源ID或私人路径。程序组件、登录问题不等于需要企业管理员新增数据权限，先查实际原因，不自动发起授权。

本Skill允许使用官方lark-cli及仓库Python工具读取题库、分析并生成看板，可在已批准的文件夹和接收范围内交付。只读取Answerbit已有采样，不创建采样任务或修改平台配置。命令执行仍需遵守当前环境权限，安装Skill不等于获得新数据权限。

## 权限申请前置报告

优先复用已获批的最小只读权限。任何需要企业管理员审批的权限，在发起授权、提交权限申请、扩权或为权限生效发布应用版本之前，先向用户报告：具体权限名称、用途、涉及的资源与数据范围、为何现有权限不足，以及可行的替代方式；等待用户决定后再继续相关操作。用户同意申请不等于企业管理员已批准，不代替平台审批。不得自行申请全量权限或借编辑权限绕过缺失的应用权限。

题库读取仍只读，不修改题文、编号、分组或标签。缺权限时报告失败环节和核实位置，停止后续Answerbit取数，不回退旧题库；已有纯离线结果仍可查看。获准使用CLI本身不证明已登录、有足够权限或已完成实时读取。

## 国家范围与隐私

国家以唯一匹配的题库工作表/题号为依据；题文里的美国等地名、采样网络地区和“欧美”等旧区域标签都不能直接改判运营国家。明确国家标签与题库冲突时列待确认，不强配题号。国家和模型是两个独立维度。

正式国家交付先核对[国家与模型配置](references/country-models.md)及同批最新飞书题库，使用有来源的名单。完整入口自动读取机器配置并输出安全采样要求；六国 TH/VN/ID/MY/JP/KR 均追加 AI Mode 与 AIO，两项均须核对平台采样配置和已有回答，不能只加展示筛选。本工具不创建计费采样任务，启用与执行须在 Answerbit 验证。日本、韩国已确认 GPT、Gemini、Google AI Mode、Google AIO 四模型，旧基础名单冲突不再阻断；Claude 继续暂缓。AIO、AI Mode、Gemini 分开，新的配置冲突或未知映射仍停止对应正式统计。题库可选提供国家页“采样模型”列，或“国家模型配置”页的“国家”“平台标识”列，不自动改原表。题库与用户确认冲突先核实。中国七模型排除 Gemini、Perplexity、Google AI Mode；东南亚四国不因旧标签纳入豆包。

用户本轮暂缓 Claude：所有国家不采样、不分析 Claude，缺少其平台标识不阻断其他模型；保留历史来源及可扩展配置，不删除母批数据。六国 AIO 与 AI Mode 要求不变，AIO 已通过品牌只读配置确认映射为 google_ai_overviews，与 AI Mode 分开；新环境或标识变化时重新只读核对，不猜值。

AIO 当前尚未采样（用户已确认），仍保留在允许国家的配置、平台筛选和看板数据位置；无有效样本显示暂无数据，比例不适用，不当作0%或未提及。后续有真实有效回答时正常纳入，不为占位自动触发采样。

取数母批保留完整原始采样，仅在独立国家副本中排除范围外和未知模型。看板、简报、Excel、行动和历史对比均从同一副本重算；配置校验值进入版本与对比条件。“国家模型排除”只保存题号、题文、平台、日期和原因，原文不进入共享看板。该审计属于本批范围，不冒充当前页内筛选结果。历史配置不同不计算误导性差值。

只向用户交付已确认国家的指标、图表、结论、行动、题单及附件，多国分别展示。平台、日期、分组和标签条件在国家范围内继续筛选并重算。HTML内嵌数据和筛选选项也须裁剪，不能只给全量看板预选国家；工具不能裁剪时停止共享并报告缺项。品牌级Key可能覆盖多国，用户自报国家不替代公司授权，分享仍须验收权限。

Key、团队/品牌ID、内部题库地址只存获批私有配置，不写入代码、常规日志或交付物。Key就绪后才读品牌资源配置（brand_id、team_id及question_bank_url）；在线题库优先使用GEO_QUESTION_BANK_URL，否则使用该私有地址。公开仓库只保留空白样例，不写入实际值。格式通过不等于平台认证或只读权限已核实。Answerbit与飞书凭证分开管理。回答原文及原文SQLite仅留获批本机；共享看板不含原文、密钥或本机查询地址。真实题库、看板、明细、数据库和私人配置不提交GitHub。

## 读取与计算

先读[指标定义](references/metric-definitions.md)，按需要读[场景应用](references/analysis-scenarios.md)。

- 每次真实拉取Answerbit前，必须实际访问私有配置所指的飞书题库并核对最新版，不能只检查URL已配置或只校验本地缓存；核对完整网格、必需国家页、修订一致性、题号唯一性，保留读取时间、修订号和内容校验值。截断、缺表或冲突时停止，不静默回退旧版。在线题库缺配置、无权限、读取不全或校验失败时，Answerbit请求必须为零，不沿用旧缓存。refresh使用最新题库；review及补读平台快照也须先在线核对，在线内容与历史题库不一致时停止并要求refresh，不改写旧批。纯离线snapshot不取平台数据，无需联网。
- 取数须分页闭合、状态和详情完整。匹配范围是飞书题库与返回题目的交集；正常及异常记录均用已确认题号。无题库候选的记录单列数量，不入指标/明细；有候选但不能唯一匹配时停止发布，输出候选核对清单，不以任务ID或占位符代题号。
- 对逐条原文运行answer_quality.py。纯报错（含仅含错误的JSON）、空白、仅复述题文、纯拒答、明确截断及有缺项证据的疑似缩水，标“数据异常”，从全部Skill有效样本分子和分母排除，不记成品牌未提及。仅长度下降仍纳入统计并单列待核查；需同条件参考和明确要求缺项同时成立才按缩水排除，不能以短代替内容判断。规则及支持范围见指标定义，均为本地初判，不断言平台故障。保留题号、原因、对照任务及本地原文；看板“回答表现→原文质量”和Excel“回答质量”区分已排除与仍纳入。旧批保留当时规则版本，需刷新才能应用新规则；平台原值不改写。
- Answerbit分组、标签与飞书分类分开保存；同维度多选取并集，跨维度取交集，标签可选全部/任一。未指定维度按该国家范围内全部。名称无法唯一对应时回平台核对ID。总体按唯一任务计数，多标签组不能相加；异常区分全批与当前范围。
- 主指标叫“提及率”：未点名题有效回答为分母，正文命中且非平台明确负面为分子；负面保留分母，褒贬并存及未知命中仍计分子。点名题单列，平台原值标“平台口径”，竞品全部正文命中的口径差异必须说明。其余公式以指标定义为准，不另造口径。
- 正式来源与正文官网链接分别计算，缺失与明确无引用分开；无实际启用计划时采样覆盖率未知。推荐仅为本地规则初判，注明版本、可判定覆盖和抽查状态，单列中立题单及非明确推荐记录。旧快照缺新字段显示“需刷新”，不要补零。
- 日本品牌写法对照须题意及采样条件一致，按原题/变体配对保留各自题号，整组汇总不能替代配对比较。

## 执行入口

仓库命令和管理员配置见[README](../../README.md)。用户要求“运行Skill”时执行完整geo_run.py流程，并显式提供`--market`国家（可重复）；该入口先裁剪独立数据库，再重算各交付。`--check`仅用于排查本机缺项，不得将预检当作已运行完成；Key、国家与题库读取就绪后应继续真实refresh。`--local-only`仅在用户本次明确要求本地交付时使用，生成本地HTML及简报，不上传。发布身份未填写时沿用程序默认应用身份，无需向用户索要identity；既有用户身份配置保持不变。飞书发布缺配置、上传或验收失败时，保留已校验的本地HTML和同批简报，状态为`delivery_status=incomplete`；一次列清发布缺项并继续可授权的修复，不默认以附件收尾。本地文件仅作备用或按用户要求交付；缺在线题库时仍停止真实取数。历史快照只能标为离线查看，不冒充本次刷新。本地refresh/snapshot/review用dashboard.py；answerbit.py用于指标查询，local_answers.py用于同批本地原文查询。合成archive流程与真实读取隔离并显著标注。

上段入口适用于一次已确认范围的分析；中央多订阅的调度、合并、分发由宿主按集中执行规程接入，仓库尚无常驻中央服务或消息投递器。不得把订阅草稿、工具可调用或单个国家成功说成全链路已部署。

用户仅要求修复或补发布已有已校验批次时，直接使用独立发布入口，不再次索要Answerbit Key、不重读题库或调用refresh；仍须核对本批范围、完整性与飞书发布授权。

每次正式refresh重读窗口内回答并完成推荐判断；含原文的有效记录以任务ID关联题号。历史review仅处理该批首轮未知，保留首轮统计与平台快照；缺原文的旧批需刷新。无可用历史数据就说明，不伪造基线或原文。

## 看板与发布

看板面向运营和管理者，使用简短业务语言：每条结论写清国家/题类、指标、数值及下一步，每句话由同批证据支持。删除“样本构成可能不同”“不代表整体表现”“不能据此推断”“仅供参考”“建议进一步核实”等泛化提醒；必须保留的限制写成具体状态和原因，如“暂不比较：两次题库版本不同”“暂无数据：本批未取得AIO回答”“待核查：12条回答缺少口碑字段”，示例数量不得写入真实结果。数字旁放样本量、分子分母和时间，方法及解释边界集中到指标说明，异常集中到可展开的数据提醒，同页同一限制只提示一次。行动写具体核查对象、核查后可优化的内容和复测方法；证据不足标“待核查”，不写成确定结论。

核心发现由运行 Agent 阅读同批、已按国家模型裁剪的数据后独立分析，分别写总体和每个国家；不要固定挑最低提及率，不复用示例、别国或上批结论。按[核心发现分析](references/core-findings.md)导出上下文、写入并校验分析，再继续同批发布；`local_ready_pending_analysis`是中间步骤，Agent须继续完成，不向用户索要额外Key或重新取数。切换国家只显示对应分析；其他筛选组合只有样本集合完全一致时才复用结论，没有匹配分析则展示该范围客观指标，不沿用原结论。未校验国家模型范围的旧看板不输出发现或行动。

按[看板展示与图表](references/dashboard-design.md)组织五页、筛选、矩阵、数据提醒、指标说明和证据行动；不把示意图数字当真实结果。默认突出数据与行动，减少重复副标题和泛化提醒；通用说明集中到指标说明或展开详情，影响判断的实际限制仍在结果旁显示。指标变化同步说明及Excel字段。所有交付来自同一成功批次。

共享范围按私有配置：缺省仅管理员；严格自动发布的公司内模式禁用外部访问。用户明确要求“上传但不改权限”时，按[已有权限单次发布](references/feishu-preview.md#已有权限单次发布)记录并核验具体文件的当前权限，只更新该文件，不再以修改权限为上传前置。已有持续项目授权覆盖本次同文件更新时直接复用，不重复确认；单次授权不扩大为其他文件、国家或长期授权。链接当前为组织内只读且协作者均获准，才可沿用；互联网公开、外部或未知成员、授权范围不清时先报告，不能将“允许对外分享”开关与当前匿名可访问混为一谈。不能把筛选当权限隔离。版本核对包含题库、范围、样本及关键内容，不能仅凭条数或ID判同。Excel可在本地生成，默认不上传。

发布前按[一次列清发布权限](references/feishu-preview.md#一次列清发布权限)核对实际应用、身份和已有连接。下载快捷命令报权限错误时，先用同一获批身份核对原生下载接口的实际响应，不直接新增协作者授权或反复登录。优先原地更新私有记录中的已知文件；未知上传结果停止重传。发布受阻时按已有权限单次发布继续同批交付，不调用refresh、不重新拉题库或Answerbit。实测通过后返回真实`/file/`预览链接和简报；严格管线的`published`、单次手动上传及未验证项分别报告，不伪造自动验收回执或覆盖上次严格成功记录。新增权限（含免审）先确认，企业审核项先报告，用户仅同意免审项时不能申请审核项或改用全量权限。

常规查重使用中央私有登记记录和已知文件标识，不列飞书目录，不将 `space:document:retrieve` 当发布必需权限。首次接入或登记缺失/损坏时，由管理员先核对历史，按[中央记录规程](references/feishu-preview.md#中央记录与版本去重)初始化或恢复；不自动认定无历史，不补造验收，不重新取数解决发布问题。严格自动发布前检查登记已就绪；用户已授权的单次链接交付另存真实操作记录，不因缺少严格回执而反复卡在初始化。只支持同一持久环境的单一串行发布者；迁移须带完整状态。

免下载交互必须在实际飞书云空间文件预览链接中验收，不能以Agent附件、下载地址、本地打开或截图代替。发布必须使用经共享校验生成的HTML，不上传本地原版；打开远端预览后实测筛选使样本量或范围变化、分页与指标说明跳转。仅附件可用或交互失败时，交付状态为待验收并说明缺项，不能声称“飞书内可交互”；不自动改为公开托管或申请新权限。

取数、匹配、查重、上传或权限/预览验收失败，不发布半批，不覆盖上一成功版本。交代失败环节、原因、受影响范围和核查位置，返回有记录的上一成功入口、原窗口与更新时间，并说明是否重新核实访问；没有旧版就明说。工作台链接仅为查找入口，不称原文直达。

## 简短报告与上次对比

标注国家/筛选范围、窗口、样本量、成功取数时间、题库和指标版本，交付：

1. **已验收飞书看板链接**：注明复用或新发布；复用另列本次核对时间，不说成重新测量。
2. **核心数据表**：3–5项，包含自算提及率，可补平台快照；列指标、来源、本次、上次、变化，标分子分母与扣负面数。平台未给分母须说明；百分点、名次、分数分别标单位，零分母不适用，未知不补零。
3. **一段结论及最多3条优先行动**：区分事实与运营推断。有证据才出行动，尽量附国家、题类、样本、题号、题文、日期、平台、核查入口、优化方向和同条件复测办法。

同一获批输出位置保留上一成功批次，失败尝试不成为基线；临时环境不能取回历史时说明无法对比。只有题库、题目范围、口径、窗口长度及来源可比才报变化，否则并列并解释。自动整批对比不随页面筛选变化，缺同条件历史时不得将整批差值冒充国家或切片变化。平台原生快照有独立范围与读取时间，不暗示随Skill筛选重算。
