# GEO 采样 Skill / GEO Sampling Skill

## 运行即配置国家订阅

默认先进入[自动订阅入口](references/scheduled-delivery.md#运行即配置订阅)，由运行本 Skill 的 Agent 读取自己的私有订阅状态，自动创建或更新原生任务。已确认的国家、时间和接收位置直接沿用；缺少关键项时一次收集，默认每天北京时间 11:00。国家只取用户声明、已验证订阅或获准的员工国家映射，不能按语言/IP猜测；“更新时间”是检查已有数据的时间，不保证平台已产生新采样。

每次运行复用该运行者的订阅和任务 ID，修改国家/时间/收件人时更新原任务，不重复创建。不把中国、美国或试点接收人写成所有运营的固定配置。内容只按该订阅国家筛选、重算，沿用本 Skill 指标及发布验收规则。

订阅字段齐全不等于已启用：原生工具、只读凭证、完整数据、看板发布及各接收路由均验证通过后，才启用或恢复每日任务；缺项时保存“待接入/暂停”状态，返回准确缺项，不生成假报告、不绕过审批。用户禁止 CLI 时，也不运行下文保留的命令行入口。用户明确仅做本次分析或离线复盘时，不新建定时订阅，走对应已有入口。

## 首次启动与凭证等待

Answerbit 的团队与品牌 ID 不写入公开 Skill、对话、常规日志或交付文件。先安全取得当前运行者的品牌级只读 Key，校验非空与格式后，才读取本机私有资源配置并尝试认证取数。资源配置由管理员一次性设置，可用 `ANSWERBIT_BRAND_ID`，或私有 JSON 文件（默认仓库 `.trial/answerbit-resources.json`，也可用 `ANSWERBIT_RESOURCE_CONFIG` 指定）中的 `brand_id`；可留存 `team_id` 作管理定位，但当前读取接口不传团队 ID。不因用户提供 Key 而自动公开 ID，也不从 Key 字符串推导品牌或团队。Key 的真实性、资源可访问性仍须由 Answerbit 响应确认；配置值不代替平台权限。


每次准备真实取数或原文复检，先向用户说明需要只覆盖 Kalodata 的 Answerbit 品牌级只读 Key，并给出预计报告时间。首次且未配置凭证时可说明：「请在隐藏输入或本机运行环境配置 Kalodata 品牌级只读 Key，配置后告诉我。以最近一周、约 1,000–3,000 条记录为例，出看板预计约 3–8 分钟，平台限流会延长。」如果窗口更大或已有实际批量进度，按任务量更新估时。

**确认 Key 已通过安全方式提供前，暂停真实运行。** 在等待期间不启动取数、复检或生成结果；等待用户完成隐藏输入或确认已配置。用户回复已配置后先检查运行入口确实能读到凭证，仍缺失则继续等待。已有安全配置可直接使用，不要求重复提交。用户明确指定已有快照的离线复盘时，可走无需 Key 的快照入口。

## 自动读取在线题库

本机配置 `GEO_QUESTION_BANK_URL` 和飞书官方 `lark-cli`（不在 PATH 时用 `LARK_CLI` 指向可执行文件）。现有应用需拥有知识库节点及电子表格的只读权限，并能阅读目标题库。不要在公开仓库写入内部题库 URL 或飞书凭证。

正式 `dashboard.py refresh` 在确认 Answerbit Key 后，自动读取在线题库，覆盖命令中指定的本地题库缓存路径，再进入 Answerbit 分析；也可用 `--feishu-bank <URL>` 临时指定。逐一读取 11 个国家工作表的完整网格，保留编号、题文、分类和各标签；排除审阅及说明页。前后修订号和结构必须一致，截断、缺表、题号冲突均停止，不静默退回旧题库。失败保留上次数据库与看板。报告保留读取时间、修订号、题数和题库校验值；无内容变化时题库校验值保持稳定。

用户明确离线时加 `--offline-bank`；没有在线 URL 配置时仍支持原 Excel 流程，但必须标注本地题库，不宣称已同步最新版。`snapshot` 和 `review` 不自动换题库，避免改写历史口径。单独验证题库可用 `python3 feishu_bank.py <私有目录/题库.xlsx>`，无需 Answerbit Key。首次在线同步额外耗时，按实际进度更新估时。

## 按国家定时推送

用户要求定时、主动推送或按国家给运营发送时，先按[国家定时推送](references/scheduled-delivery.md)核实运行 Agent 的持久调度、数据读取、已验收发布及消息路由能力，再用原生调度工具创建或更新任务，不能靠本 Skill 文本声称已经后台运行。用户禁止 CLI 时不调用终端、shell、CLI 或改用其他平台的定时器；原生能力不足则报告缺项。

每个接收人须绑定已验证的国家范围和准确的会话/用户标识。普通双人私聊不等于该运营与智能体的会话，群路由须验证成员仅为获准接收者及必要智能体。先完成一次性定时实发测试，再区分报告调度、消息送达和真实数据链路的验收状态。相同任务复用更新，不重复创建。

## 手动运行与交付

运行者提供品牌级只读 Key 后，从仓库根目录运行 `python3 geo_run.py <在线题库缓存.xlsx> <私有目录/dashboard.sqlite> <私有目录/GEO运营看板.html> --excel <私有目录/GEO采样明细.xlsx>`。管理员需先配置在线题库与私有 `GEO_FEISHU_CONFIG`；默认读取北京时间最近七个自然日的全部范围；指定日期时加 `--begin YYYY-MM-DD --end YYYY-MM-DD`。仅本地或离线复盘继续用 `dashboard.py`，不冒充已完成飞书交付。

**默认交付已验收的飞书看板链接和同批简短报告**。

每次按[飞书预览交付](references/feishu-preview.md)完成远端查重、共享与验收。`reused` 才可交付已有链接；`pending_acceptance` 仍是待验收，不是成功发布。Agent 用可用浏览器实际验收后保存精确绑定文件及校验值的证据，再执行验收入账命令，得到 `published` 后交付新链接。不能为了自动化跳过实际权限与交互检查或填写未经观察的通过值。Answerbit Key 与飞书授权分开管理。

- 对话内给一份简短报告，按下文「默认报告」的核心数据表、结论与判断、优先行动项三部分交付。
- 飞书看板链接注明「复用已有版本」或「新发布版本」、数据窗口和最后成功取数时间；另标本次核对时间，不把复用说成重新测量。权限未用真实运营账号验证前，仅向已批准管理员交付。共享版只有工作台回查，不含本机原文入口。
- `GEO采样明细.xlsx` 仍可在本机生成，默认不上传或作为附件交付。用户明确要求并确认适合共享后再交付。包含可筛选的回答记录及异常题号，原文留在本机 SQLite；内部题文、题号和统计不提交公开仓库。

**对账范围是飞书题库和 Answerbit 返回题目的交集。** 正常回答和异常记录都使用已确认的飞书题号。没有题库候选的记录单独计数，不纳入指标和 Excel 明细，不阻止交付。只有题库内存在候选但题号无法唯一确认时，才保留上一批并交付题号待核对清单。按题文、任务 ID 和候选编号回飞书题库或 Answerbit 核对，勿用任务 ID 或占位符作题号。

查重失败、版本信息不足、上传或验收失败时，明确环节、影响整批与核实入口，返回有记录的上一成功链接及原数据窗口与时间，并注明本次是否重新核实访问。没有上一份时明说。不能把待验收链接、目录链接或本机路径写成已发布看板，也不覆盖上一成功版本。

**查询同批数据库时**，在获批本机的仓库根目录运行 `python3 answerbit.py query <私有目录/dashboard.sqlite>`，可离线读取指标和异常，可附 `--group-id` 与 `--tag-id`。查具体回答时，将同批 HTML 和 SQLite 保存在同一台电脑，运行 `python3 local_answers.py <私有目录/dashboard.sqlite> <私有目录/GEO运营看板.html>`，打开返回的本机地址，点「非明确推荐记录」的「查看原文」。查询期间保留该进程。数据库访问只读，无需 Answerbit Key。

每条通过校验并唯一匹配题号的有效回答按任务 ID 将题文和原文保存在本机 SQLite。HTML 只含统计与回查索引。含原文的 SQLite 和本机查询地址留在获批本机，勿通过飞书附件、GitHub 或对话转发。旧快照需重新取数才有原文。Answerbit 原生概览、趋势和引用排行使用各自的全范围快照，单独标明读取时间与范围；看板筛选重算 Skill 分析。刷新失败时保留最后成功数据，并在结果及旧看板顶部标明失败阶段。用户明确要离线复盘时可运行 `dashboard.py snapshot` 读取已有 SQLite，标注批次时间。

看板以深蓝侧栏组织五个主模块：总览、市场与竞品、问题与行动、来源与口碑详情、指标说明。总览用三张卡突出提及率、首次出现第一比例、Kalodata 负面与褒贬并存（负面和褒贬并存分别列数量及比例，均标分母）。新增国家 × 题类矩阵，可切换 Answerbit 分组或标签，限定未点名题，各格独立展示比例和分子分母；多标签可重叠，不相加。颜色仅辅助定位，不解释为市场优劣。不采用未经确认的固定样本阈值，仅提示矩阵内最小样本格。展示六类平台口碑堆叠条、数量和统一分母，可识别字段覆盖率 = 非未知回答 ÷ 全部有效回答，不把未提及当中性。无数据时不绘图。平均首次出现名次保留在详情。首页仍有一段判断、最多三条优先行动和数据状态。官网引用移至来源与口碑详情，保留全部口碑状态。平台快照和对照分析位于市场与竞品，推荐判断与原文记录位于问题与行动。切页保留筛选和对照条件，平台页独立使用原生快照口径。视觉参考只控制样式，不提供数字、趋势或市场结论。

每次正式 `refresh` 都重新读取本次窗口的回答，在同次运行自动完成推荐判断并生成看板。用户明确要求补做历史快照的复检时，使用 `python3 dashboard.py review <题库.xlsx> <现有快照.sqlite> <现有看板.html>`。历史复检只重读首轮未知，保留该批首轮统计和平台快照。用户明确要求暂缓平台旧任务时加 `--defer-unavailable`。回答表现页展示合并后的推荐判断，非明确推荐表内的市场、平台、日期、分组、标签与顶部双向同步，可再筛推荐判断和待确认原因。对照分析逐条列出指标定义及差值，当前范围来自顶部筛选，对照范围在本页独立设置。

看板支持市场、平台、分组和标签多选。维度间取交集，标签可选择匹配全部或任一。对照分析用独立条件重算两个范围，先展示关键差异，详细指标可展开，标注样本、分母、差值与重叠量。两组竞品集合一致时才比较提及份额。Answerbit 原生区沿用概览指标卡、品牌趋势和平台竞品排行的结构。

运营行动单独展示未点名题缺席、官网引用、首次位置、口碑和推荐判定中的可回查线索。每项按证据选择一个切片和代表题，区分现象、建议动作和复测口径。样本不足时提示先复核个例。

## 按运营场景解读

读取[运营场景与指标](references/analysis-scenarios.md)，按 Answerbit 实际分组、标签名称识别场景：发现度、数据引用看提及率及首次出现第一比例；对比场景拆为未点名题看提及率、点名题看平均首次出现名次；品牌健康看 Kalodata 平台情感及官网引用。默认全量取数不变，看板随筛选显示各场景的样本量、指标和解释。

标签「3」是业务描述，不是固定 tag_id，不凭数字或截图推断接口 ID。标签名称缺失或无法映射时说明未识别，不擅自把所有题归入场景。题文是否点名依据 Answerbit 返回题文和审核别名，不由标签覆盖。发现度、数据引用题预期未点名且含 TikTok 语境；有偏离时提示回 Answerbit 核对，仍按实际题文计算。「首位」为首次出现第一比例；「排名」为正文首次出现名次，非平台原生排名，必须分别注明。数据引用场景可补充正式来源和正文官网链接，二者不混算。

飞书题库的内部入口由运行环境 `GEO_QUESTION_BANK_URL` 配置，不写入公开源码；未配置时隐藏看板题库链接，仍可按题号到公司题库核对。

## 看板指标说明模块

每份 HTML 看板都须有独立的「指标说明」分页，离线可读。按样本与筛选、品牌表现、官网引用、推荐与口碑、Answerbit 平台快照与对照分组。每项按「看什么、怎么算、注意什么」组织，写清来源、分子、分母、去重、筛选、缺失和可比条件；指标卡链接到对应说明，平台返回值单独标注。定义以[指标定义](references/metric-definitions.md)为准，更新算法时同步更新看板说明和 Excel 对应字段。交付前核对指标分页可打开，说明与实际数值口径一致。

## 运行前

先读[指标定义](references/metric-definitions.md)。运行前凭证按「首次启动与凭证等待」执行；范围按用户需求确定。

- 用户未指定分组或标签时，相应维度按全部计算。指定一项时只筛该项，两项都指定时取交集。名称能从本地已核实的元数据唯一对应 ID 时直接使用；用户指定的名称有歧义或无法确认时，请用户提供 ID 或到 Answerbit「用户提问」核对。命令行 `answerbit.py` 只支持一个分组；多分组使用全量看板筛选。

用户明确要求命令行指标或简报时，可调用 `python3 answerbit.py refresh <飞书题库导出.xlsx> <本地库.sqlite> --begin YYYY-MM-DD --end YYYY-MM-DD`。使用用户要求的日期窗，未指定时用北京时间最近七个自然日（含今天）并标注。题库使用已配置的全国家飞书题库导出。只读取现有记录，不触发采样或修改 Answerbit。真实输出使用独立路径，例如 `.trial/answerbit.sqlite`。

分析 `refresh` 返回的摘要。仅有回答记录时覆盖率未知，不把已返回记录当计划分母。合成试跑由独立的 `archive.py` 工具执行，与本 Skill 的真实取数入口分开。

分析品牌官网链接时读取 `website_links`，按 Kalodata、FastMoss 分别展示正文官网链接出现率和正式来源官网命中率，以及正式来源字段覆盖率。两项独立计算，同一回答可以各命中一次。用户要求分组或标签明细时，再使用 `website_links_by_group` 或 `website_links_by_tag`。旧快照没有该字段时先刷新。

完整内容指标报告读取 `content`，用 `dimensions` 按市场、点名状态及用户选定范围解释提及、份额与位置。推荐只看 Kalodata，始终单列「中立推荐」题单，按题号归并并保留每条回答的日期、平台和分组。在 Answerbit 用分组、题文、日期和平台回查，在飞书用题号回查。推荐初判注明规则版本、可判定覆盖及抽查状态；平台口碑仅用已核实的枚举映射，未确认时展示未知和平台原值分布。旧快照有 `content_status=需刷新` 时，刷新到新文件，旧快照可继续查询原指标。

## 默认报告

主指标统一命名「提及率」。只取 Answerbit 返回题文未点名 Kalodata 或审核别名的有效回答，在其正文命中分子中扣除平台明确负面，分母仍保留这些负面回答。保留褒贬并存和口碑未知命中。点名题另作品牌介绍、推荐及口碑分析。卡片列分子、分母和扣负面数量，详细规则从卡片跳转指标说明。平台快照标注「平台口径」，竞品全部正文命中与 Kalodata 的口径差异必须说明。

先标注数据窗口、成功取数时间、筛选范围和有效回答数，然后按顺序输出三部分。

1. **核心数据表**。选最能支持本次判断的 3–5 项数据，必须包含 Skill 自算的「提及率」，同时可采用可用的 Answerbit 平台快照，例如品牌提及率、平均排名、曝光效果分数。列为「指标、来源、本次、上次、变化」。Skill 比例写明分子和分母，平台没有返回分母时注明。比例变化用百分点，排名用名，分数用分；零分母显示不适用，未知显示暂无数据。
2. **一段结论与判断**。概括最重要的变化、涉及市场或题类，以及判断依据和必要限制。区分数据事实和运营推断。没有可比批次时只解释本次，避免给出增长结论。
3. **优先行动项**。最多三项，按重要性排列为 P1、P2、P3。有证据的项目不足三项时按实际数量输出。每项说明针对哪个市场、题类或平台，建议做什么、去哪里核实，以及下一轮如何同条件复测。涉及具体问题时附飞书题号、日期和平台。

**自动比较上次测量**。每次复用同一个获批的稳定输出位置，保留上一份成功 HTML 作为基线，失败尝试不成为基线。任务环境只提供临时目录时，先检查是否有权限取回上次产物；没有可读取的历史文件时明确说明无法自动比较。优先对比两次平台快照的同名指标，平台缺项时对比同口径 Skill 指标。首次运行或输出位置没有历史文件时说明无历史结果。题库版本、题目范围、分析口径或窗口长度不同或缺少历史范围证据时，并列数据并说明限制，不给直接变化结论。离线重绘同一批时沿用已有上次基线。自动对比按两批全量范围展示，与当前页面筛选分开；指定筛选范围的简报不能把整批差值当作该范围的变化。

市场、平台、分组和标签都保留为分析维度，默认只展示与结论相关的切片。合成测试显著标注。

## 选图

看板和用户另行要求的完整报告按分析问题选图。对话简报始终保留核心数据表。

- **折线图**用于同口径、同采样条件下至少两个可比轮次的时间变化。横轴用采样日期或轮次，缺样标为缺失。
- **柱状图**用于同一窗口内的平台、市场、题类或品牌写法对比。优先用环境内可用的标准图表工具。比较两项官网链接指标时按指标分组，每组并列品牌，使用相同的零起点百分比轴。柱端标出比例及各自的分子和分母，缺失值标为未知。条件不同则说明差异，避免把分组差异解释为市场或平台效果。
- **散点图**用于同一分析单元上两个数值指标的关系。每个点必须有一对可核对的数值，标明点代表什么，结论限于观察到的关系。
- **饼图或环形图**用于同一总体内互斥且完整的构成，标注总量和占比。可重叠的多标签、多个品牌提及率适合用柱状图。

从查询结果直接生成并展示图表，标明指标、筛选范围、时间和分母。发布前核对数值与快照一致，并预览检查图例、轴刻度和中文标签是否清晰、无遮挡。图里已展示的分组无需再附整表。没有合适的比较、趋势或构成数据，或图表无法可靠呈现时，用简表。

完整报告可按问题选图。竞品提及和份额图限定在相同竞品集合中。首次出现比例与平均名次分母不同，优先并排列表；推荐优先用分类表和中立题单。口碑映射未核实或覆盖不足时，只列可核对的数据。

Answerbit 的分组与标签是独立维度，飞书题库的分类也单独保留。用 `answerbit_groups` 和 `answerbit_tags` 分析平台分组及标签，区分标签 ID 和类型。用 `--group-id` 和可重复的 `--tag-id` 按交集筛选；未指定的维度省略参数。总体按唯一任务计数，同一道题可带多个标签。缺失或冲突的标签元数据标为未知。命令返回的异常清单覆盖整个取数批次，报告时区分所选范围内的问题和批次级问题。

日本品牌名对照先看题目使用的写法，再看回答使用的写法。按对应原题和日文品牌名变体配对，保留各自题号。仅比较题意一致且采样条件一致的对照题；整组汇总不能替代配对比较。旧口径没有日文拆分数据，需重新取数后才可用新口径对比。


核心指标卡仅在上次同范围、同口径且可比时显示百分点变化。顶部筛选改变后整批基线不适用于切片，卡片提示暂不比较。旧批未保存对应指标或分母无效时明确原因，禁止伪造趋势线。矩阵点击后同步当前国家与题类筛选，口碑、结论、行动随之重算。

行动详情页保留全部可定位的问题切片及代表证据，不只取每类第一项；首页优先显示最多三个不同问题类型，避免同质建议占满。每条建议标明运营推断及复测方法。

首页数据状态只显示一条「数据提醒」，默认收起明细。提醒明确区分全批未匹配/待核对和当前筛选内的口碑未知、引用字段缺失；缺少异常统计时显示未知，不能补零。点击查看详情后列出原因、数量、影响范围和核查入口，与同批 Excel「数据异常」对应。点名题专题放在市场与竞品内，随全部筛选和题文状态更新，保留有效回答、扣负面提及、推荐各类初判与未知、六类 Kalodata 平台口碑，分别标分母；本地规则初判不得写成人工确认推荐率。
