# GEO 采样 Skill / GEO Sampling Skill

## 运行前

先读[指标定义](references/metric-definitions.md)。每次真实分析前确认凭证，并按用户需求确定分析范围。已提供的内容无需重复询问。

- 当前运行者在本机提供仅覆盖目标品牌的 Answerbit 只读 Key。交互终端支持隐藏输入，Agent 和其他非交互环境从当前用户的 `ANSWERBIT_API_KEY` 读取。品牌 ID 通过 `ANSWERBIT_BRAND_ID` 配置。密钥只通过本机的隐藏输入或环境配置提供，勿在对话、命令或报告中显示。缺少凭证或认证失败时停止真实分析。
- 用户未指定分组或标签时，相应维度按全部计算。指定一项时只筛该项，两项都指定时取交集。名称能从本地已核实的元数据唯一对应 ID 时直接使用；用户指定的名称有歧义或无法确认时，请用户提供 ID 或到 Answerbit「用户提问」核对。单个命令支持一个分组，选择多个分组时分开报告。

调用 `python3 answerbit.py refresh <飞书题库导出.xlsx> <本地库.sqlite> --begin YYYY-MM-DD --end YYYY-MM-DD`。使用用户要求的日期窗，未指定时用北京时间最近七个自然日（含今天）并标注。题库使用已配置的全国家飞书题库导出。只读取现有记录，不触发采样或修改 Answerbit。真实输出使用独立路径，例如 `.trial/answerbit.sqlite`。

分析 `refresh` 返回的摘要。仅有回答记录时覆盖率未知，不把已返回记录当计划分母。合成试跑由独立的 `archive.py` 工具执行，与本 Skill 的真实取数入口分开。

分析品牌官网链接时读取 `website_links`，按 Kalodata、FastMoss 分别展示正文官网链接出现率和正式来源官网命中率，以及正式来源字段覆盖率。两项独立计算，同一回答可以各命中一次。用户要求分组或标签明细时，再使用 `website_links_by_group` 或 `website_links_by_tag`。旧快照没有该字段时先刷新。

## 默认报告

首句给出最重要的结论和有效样本数，随后标注所选分组、标签、查询窗口、截至时间和题库版本。默认展示品牌提及率、未点名题提及率和官网引用率，按用户问题选择更相关的指标。能用一张图说明结论时优先出图，汇总指标用短句补充；否则用一张最多三行的指标表。比例带分子和分母，零分母显示不适用。

结尾固定用两条，保持简报长度。

- **运营建议与优化方向**。从本次分组和标签中选一个值得处理的点，写清针对哪类题或平台、建议做什么以及下一轮怎么复测。样本或证据不足时，先建议补齐或核对样本。
- **存在的问题与核实入口**。写清问题、受影响范围和平台入口。分组或标签回 Answerbit「用户提问」，漏采、引用缺失或回答状态回「大模型回答记录」，题号或题文冲突回飞书题库。尽量附题号、日期、平台或任务 ID。无法验证直达链接时，给出页面名称及检索条件。没有发现异常时说明检查范围，逐条明细按需展开。

市场、平台、分组和标签都保留为分析维度，默认只展示与结论直接相关的切片。合成测试显著标注。

## 选图

根据本次分析问题选一种图，默认最多一张。用户明确要求比较多个不同问题时，再分别出图。

- **折线图**用于同口径、同采样条件下至少两个可比轮次的时间变化。横轴用采样日期或轮次，缺样标为缺失。
- **柱状图**用于同一窗口内的平台、市场、题类或品牌写法对比。优先用环境内可用的标准图表工具。比较两项官网链接指标时按指标分组，每组并列品牌，使用相同的零起点百分比轴。柱端标出比例及各自的分子和分母，缺失值标为未知。条件不同则说明差异，避免把分组差异解释为市场或平台效果。
- **散点图**用于同一分析单元上两个数值指标的关系。每个点必须有一对可核对的数值，标明点代表什么，结论限于观察到的关系。
- **饼图或环形图**用于同一总体内互斥且完整的构成，标注总量和占比。可重叠的多标签、多个品牌提及率适合用柱状图。

从查询结果直接生成并展示图表，标明指标、筛选范围、时间和分母。发布前核对数值与快照一致，并预览检查图例、轴刻度和中文标签是否清晰、无遮挡。图里已展示的分组无需再附整表。没有合适的比较、趋势或构成数据，或图表无法可靠呈现时，用简表。

Answerbit 的分组与标签是独立维度，飞书题库的分类也单独保留。用 `answerbit_groups` 和 `answerbit_tags` 分析平台分组及标签，区分标签 ID 和类型。用 `--group-id` 和可重复的 `--tag-id` 按交集筛选；未指定的维度省略参数。总体按唯一任务计数，同一道题可带多个标签。缺失或冲突的标签元数据标为未知。命令返回的异常清单覆盖整个取数批次，报告时区分所选范围内的问题和批次级问题。

日本品牌名对照先看题目使用的写法，再看回答使用的写法。按对应原题和日文品牌名变体配对，保留各自题号。仅比较题意一致且采样条件一致的对照题；整组汇总不能替代配对比较。旧口径没有日文拆分数据，需重新取数后才可用新口径对比。
