# GEO 采样 Skill / GEO Sampling Skill

## 启动确认

用户主动运行时，一次收集以下信息；本次对话已明确的不要重复问。

1. **运营国家**：询问负责哪些国家，可多选。历史配置只作候选，请用户确认沿用或调整；不按语言、IP或采样网络地区猜。
2. **只读 Key**：引导在隐藏输入或获批环境安全配置仅覆盖 Kalodata 的品牌级只读 Key。已有安全配置可检查后复用，不要求聊天明文提交。告知预计耗时，按实际任务量和限流更新；缺少国家确认或可用 Key 时暂停真实取数、复检与发布。离线复盘指定快照时无需 Key。
3. **推送需求**：询问是否定时、频率、时间和接收位置；推荐并默认每周一北京时间上午11:30，用户确认后才设置。已有计划展示后确认沿用或调整，单次分析不建订阅。具体按[国家定时推送](references/scheduled-delivery.md)。

只读取已有采样，不创建采样任务或修改 Answerbit。用户禁止CLI时不调用命令行入口；运行 Agent 缺等价原生能力就列明缺项，不以文档配置代替实际接通。

## 国家范围与隐私

只向用户交付已确认国家的指标、图表、结论、行动、题单及附件，多国分别展示。平台、日期、分组和标签条件在国家范围内继续筛选并重算。HTML内嵌数据和筛选选项也须裁剪，不能只给全量看板预选国家；工具不能裁剪时停止共享并报告缺项。品牌级Key可能覆盖多国，用户自报国家不替代公司授权，分享仍须验收权限。

Key、团队/品牌ID、内部题库地址只存获批私有配置，不写入代码、常规日志或交付物。Key就绪后才读品牌资源配置（brand_id、team_id及question_bank_url）；在线题库优先使用GEO_QUESTION_BANK_URL，否则使用该私有地址。公开仓库只保留空白样例，不写入实际值。格式通过不等于平台认证或只读权限已核实。Answerbit与飞书凭证分开管理。回答原文及原文SQLite仅留获批本机；共享看板不含原文、密钥或本机查询地址。真实题库、看板、明细、数据库和私人配置不提交GitHub。

## 读取与计算

先读[指标定义](references/metric-definitions.md)，按需要读[场景应用](references/analysis-scenarios.md)。

- 每次真实拉取Answerbit前，必须实际访问私有配置所指的飞书题库并核对最新版，不能只检查URL已配置或只校验本地缓存；核对完整网格、必需国家页、修订一致性、题号唯一性，保留读取时间、修订号和内容校验值。截断、缺表或冲突时停止，不静默回退旧版。在线题库缺配置、无权限、读取不全或校验失败时，Answerbit请求必须为零，不沿用旧缓存。refresh使用最新题库；review及补读平台快照也须先在线核对，在线内容与历史题库不一致时停止并要求refresh，不改写旧批。纯离线snapshot不取平台数据，无需联网。
- 取数须分页闭合、状态和详情完整。匹配范围是飞书题库与返回题目的交集；正常及异常记录均用已确认题号。无题库候选的记录单列数量，不入指标/明细；有候选但不能唯一匹配时停止发布，输出候选核对清单，不以任务ID或占位符代题号。
- Answerbit分组、标签与飞书分类分开保存；同维度多选取并集，跨维度取交集，标签可选全部/任一。未指定维度按该国家范围内全部。名称无法唯一对应时回平台核对ID。总体按唯一任务计数，多标签组不能相加；异常区分全批与当前范围。
- 主指标叫“提及率”：未点名题有效回答为分母，正文命中且非平台明确负面为分子；负面保留分母，褒贬并存及未知命中仍计分子。点名题单列，平台原值标“平台口径”，竞品全部正文命中的口径差异必须说明。其余公式以指标定义为准，不另造口径。
- 正式来源与正文官网链接分别计算，缺失与明确无引用分开；无实际启用计划时采样覆盖率未知。推荐仅为本地规则初判，注明版本、可判定覆盖和抽查状态，单列中立题单及非明确推荐记录。旧快照缺新字段显示“需刷新”，不要补零。
- 日本品牌写法对照须题意及采样条件一致，按原题/变体配对保留各自题号，整组汇总不能替代配对比较。

## 执行入口

仓库命令和管理员配置见[README](../../README.md)。具备获批命令行环境时，完整流程用geo_run.py，并显式提供`--market`国家（可重复）；该入口先裁剪独立数据库，再重算各交付。`--check`仅检查本机缺项，`--local-only`不上传。缺飞书配置时可完成本地分析并标待发布，缺在线题库时停止真实取数；本地导出仅用于已存快照的离线查看。本地refresh/snapshot/review用dashboard.py；answerbit.py用于指标查询，local_answers.py用于同批本地原文查询。不要把命令行工具声称为无CLI原生连接器。合成archive流程与真实读取隔离并显著标注。

每次正式refresh重读窗口内回答并完成推荐判断；含原文的有效记录以任务ID关联题号。历史review仅处理该批首轮未知，保留首轮统计与平台快照；缺原文的旧批需刷新。无可用历史数据就说明，不伪造基线或原文。

## 看板与发布

按[看板展示与图表](references/dashboard-design.md)组织五页、筛选、矩阵、数据提醒、指标说明和证据行动；不把示意图数字当真实结果。指标变化同步说明及Excel字段。所有交付来自同一成功批次。

默认按[飞书交付规程](references/feishu-preview.md)查重、上传并验收：reused可复用已验收链接，pending_acceptance不是发布成功，published后才交付新版本。版本核对包含题库、范围、样本及关键内容，不能仅凭条数或ID判同。Excel可在本地生成，默认不上传。

取数、匹配、查重、上传或权限/预览验收失败，不发布半批，不覆盖上一成功版本。交代失败环节、原因、受影响范围和核查位置，返回有记录的上一成功入口、原窗口与更新时间，并说明是否重新核实访问；没有旧版就明说。工作台链接仅为查找入口，不称原文直达。

## 简短报告与上次对比

标注国家/筛选范围、窗口、样本量、成功取数时间、题库和指标版本，交付：

1. **已验收飞书看板链接**：注明复用或新发布；复用另列本次核对时间，不说成重新测量。
2. **核心数据表**：3–5项，包含自算提及率，可补平台快照；列指标、来源、本次、上次、变化，标分子分母与扣负面数。平台未给分母须说明；百分点、名次、分数分别标单位，零分母不适用，未知不补零。
3. **一段结论及最多3条优先行动**：区分事实与运营推断。有证据才出行动，尽量附国家、题类、样本、题号、题文、日期、平台、核查入口、优化方向和同条件复测办法。

同一获批输出位置保留上一成功批次，失败尝试不成为基线；临时环境不能取回历史时说明无法对比。只有题库、题目范围、口径、窗口长度及来源可比才报变化，否则并列并解释。自动整批对比不随页面筛选变化，缺同条件历史时不得将整批差值冒充国家或切片变化。平台原生快照有独立范围与读取时间，不暗示随Skill筛选重算。
