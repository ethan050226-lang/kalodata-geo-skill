# GEO 采样 Skill / GEO Sampling Skill

先读[指标定义](references/metric-definitions.md)。每次读取真实数据都由当前运行者在本机提供仅覆盖目标品牌的 Answerbit 只读 Key。交互终端支持隐藏输入，Agent 和其他非交互环境从当前用户的 `ANSWERBIT_API_KEY` 读取。品牌 ID 由当前用户通过 `ANSWERBIT_BRAND_ID` 配置。勿要求用户在对话中发送密钥、在命令里拼接密钥或复用其他运行者的凭证。缺少配置或认证失败时报告阻塞，停止本次真实数据分析。

调用 `python3 answerbit.py refresh <飞书题库导出.xlsx> <本地库.sqlite> --begin YYYY-MM-DD --end YYYY-MM-DD`。使用用户要求的日期窗，未指定时用北京时间最近七个自然日（含今天）并标注。题库使用已配置的全国家飞书题库导出。只读取现有记录，不触发采样或修改 Answerbit。真实输出使用独立路径，例如 `.trial/answerbit.sqlite`。

分析 `refresh` 返回的摘要。仅有回答记录时覆盖率未知，不把已返回记录当计划分母。合成试跑由独立的 `archive.py` 工具执行，与本 Skill 的真实取数入口分开。

## 默认报告

首句给出最重要的结论和有效样本数，随后用一行标注查询窗口、截至时间和题库版本。只用一张最多三行的指标表，默认展示品牌提及率、未点名题提及率和官网引用率，按用户问题选择更相关的指标。比例带分子和分母，零分母显示不适用。

结尾最多两条，优先写会改变结论的数据限制和需要回平台处理的异常。异常只报数量、影响和回查入口，逐条明细按需展开。市场、平台、分组和标签都保留为分析维度，默认只展示与结论直接相关的切片；用户点名维度或要求详细报告时再展开。合成测试显著标注；趋势需要可比轮次。

Answerbit 的分组与标签是独立维度，飞书题库的分类也单独保留。用 `answerbit_groups` 和 `answerbit_tags` 分析平台分组及标签，区分标签 ID 和类型。用户指定范围时，用 `--group-id` 和可重复的 `--tag-id` 按交集筛选。总体按唯一任务计数，同一道题可带多个标签。缺失或冲突的标签元数据标为未知，异常范围以整个取数批次为准。

日本品牌名对照先看题目使用的写法，再看回答使用的写法。按对应原题和日文品牌名变体配对，保留各自题号。仅比较题意一致且采样条件一致的对照题；整组汇总不能替代配对比较。旧口径没有日文拆分数据，需重新取数后才可用新口径对比。

异常给出受影响的题号、平台、轮次或记录 ID，以及回查平台。源记录链接未核实时，用这些定位信息引导运营回平台查询。
