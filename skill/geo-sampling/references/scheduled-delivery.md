# 国家定时推送

## 运行即配置订阅

由运行本 Skill 的 Agent 根据用户需求配置，不绑定某个智能体、国家试点或固定接收人。单次分析不强制开通订阅。

1. **确认运营国家与凭证。** 向用户确认负责国家（可多国），引导安全提供或检查品牌级只读 Key；本次已明确的不重复问。两项齐备前不真实取数或发布。
2. **询问推送需求。** 问：“需要定时推送吗？希望多久一次、哪天几点、发到哪里？推荐每周一北京时间上午11:30，汇总前七个完整自然日；也可自定义或仅做本次分析。”首次配置必须等用户回答；接受推荐但未另指定时间时，默认每周一11:30、Asia/Shanghai。未回复不自动建任务。已有订阅时展示当前设置，确认沿用或调整，不擅自将自定义时间改成默认值。用户已明确频率、时间和接收位置时直接采用。未指定时区默认北京时间并告知；其他时区需按用户要求保存，并说明夏令时影响。
3. **按身份准备内容。** 仅纳入确认国家，范围内平台、分组、标签默认全部，用户指定时按交集筛选。按范围重算指标、结论和行动，多国分别展示。HTML内嵌数据、筛选可选项、题单、简报和附件均裁剪到该范围，不能只预选国家而交付全量数据。无法裁剪时停止共享。国家自报不代替公司权限。
4. **检查能力并配置。** 检查当前 Agent 的持久调度、获批数据连接、计算、飞书发布验收和主动消息能力。用平台原生工具创建或更新计划，复用稳定订阅及任务 ID，先查重，不重复建任务、不接管他人任务。缺能力时保存待接入/待验证配置并列出缺项，不声称已后台运行。遵守当前用户的工具限制；禁止CLI时不得绕过。
5. **验收后启用。** 验证实际定时触发、目标接收、完整真实数据、发布权限与预览、无更新静默和异常通知。未通过不启用；不能仅凭创建成功或本人会话送达就声称其他运营已接收。返回国家、频率、时间、时区、窗口、接收位置、任务ID、状态与下一次执行时间；暂停或待接入状态不报为已启用。用户可随时调整频率、国家或暂停，更新同一任务并重验受影响部分。

## 私有订阅状态

仅存获批私有环境，不提交公开仓库。安全凭证只保留引用，不记录密钥明文。下面仅为待配置结构示例，不代表任务已创建：

```json
{
  "subscription_id": "private_stable_subscription_id",
  "owner": "verified_current_operator",
  "timezone": "Asia/Shanghai",
  "frequency": "weekly",
  "weekdays": ["MO"],
  "local_time": "11:30",
  "window": "previous_7_complete_days",
  "schedule_confirmed": false,
  "status": "waiting_for_confirmation",
  "routes": [{"markets": [], "recipient": "verified_recipient", "destination": "verified_agent_conversation", "verified": false}],
  "scheduler_job_id": null,
  "last_success_by_scope": {}
}
```

国家和接收者须确认，不能按语言、IP、采样地区或同名联系人猜。接收路由与文件共享范围必须一致，不自动扩大权限。无人值守任务沿用已确认国家和安全凭证，不每次索取Key；凭证失效或权限变化则停止并通知。

## 每次定时运行

- 按已确认计划检查已有采样，不创建或修改 Answerbit 采样任务。默认取触发日D的D-7至D-1七个完整北京时间自然日；默认周一执行对应上一周周一至周日。自定义频率不自动改变数据窗口，需在回执说明；其他时区的触发时间不改变数据窗口口径，除非用户明确要求。
- 读取最新获批题库与已有回答，完整对账并唯一匹配题号，沿用现有指标定义。提及率仍为未点名题、扣除明确负面，推荐注明本地规则初判。
- 对各范围核对上次成功版本：窗口、品牌、题库、范围、样本集合、指标口径与关键回答/判定、来源、口碑和状态校验值。不能仅凭条数或样本ID判无变化。历史证据不足时说明，不能伪造基线。
- 无变化时默认静默，用户要求固定周期也收状态简报时按其确认设置执行。有变化且数据、权限与预览全部验收通过后，发送已验收看板和同批简报；无法验收时通知待验收，不预填通过。
- 失败不发布半批、不覆盖上一成功版本。异常通知指出国家/窗口、失败环节、原因、影响、上一成功入口和时间，以及到Answerbit、飞书题库或权限管理核实的位置；没有旧版时明说。渠道本身失败时记录并使用预先批准的备用渠道，没有备用渠道则说明无法保证通知。
- 按接收者、范围和验收版本记录投递，已送达者不重复发送，补发只针对失败者。私有状态不含回答原文或密钥。回答原文和原文库不推送，Excel默认留本地。

## 通知内容

看板链接和简短报告：国家、数据窗口、成功读取/发布时间、题库与口径版本、3–5项核心数据及分子分母、一段有依据的结论、最多3条具体行动。尽量附题号、题文、日期、平台和分组回查定位；工作台入口不称原文直达。工具能力和运行条件不足时明确限制，不承诺任意Agent安装后即可推送。

## 验收场景

| 用户需求或状态 | 预期行为 |
|---|---|
| 接受推荐 | 配置每周一11:30、Asia/Shanghai，回读下一次时间 |
| 每周三下午3点 | 按周三15:00设置，不沿用默认周一 |
| 已有自定义订阅，再次运行 | 展示设置并确认沿用或修改，更新原任务，不重复创建 |
| 未回复是否定时或时间 | 等待确认，不自动启用 |
| 仅单次分析 | 不创建订阅 |
| Key齐备但国家未确认 | 不真实取数、不默认发全量 |
| 缺连接器、发布或接收验证 | 保留待接入/验证，不启用、不发送假报告 |
| 异常或上传中断 | 保留上一成功入口，按已验证渠道通知 |
