# 集中执行与国家推送

## 执行位置与统一入口

采用中央环境运行现有 Skill、项目管理员创建的统一 Agent 接收需求和推送的方式。统一入口名称、真实用户、题库和目录地址仅存私有配置。运营自己的 Agent 可以调用获批查询入口，但不各自配置品牌 Key、重新拉取题库和回答或维护发布任务；没有已接通的查询入口时如实说明，不能声称 Agent 间已互通。

| 角色 | 职责与边界 |
|---|---|
| 统一 Agent | 确认国家、时间、时区和接收位置，提交获准请求，返回已验收链接与简报，处理调整/暂停。不能凭运营自报国家扩大数据权限。 |
| 中央执行环境 | 复用获批连接，串行运行题库读取、Answerbit 取数、指标计算、国家裁剪、共享校验、版本查重和发布；保管私有原文、凭证引用及成功状态。 |
| 验收环境 | 打开实际飞书候选，核对完整性、访问范围及交互；可以是中央环境已有浏览器或另一个获批验收环境。没有真实验收证据就不标发布成功。 |
| 调度与投递宿主 | 持久保存订阅与任务 ID，按时触发中央流程，以获准应用身份发给指定用户/群，记录实际投递结果。Skill 文案不能赋予宿主这些能力。 |

优先复用仓库 `geo_run.py`、`feishu_bank.py`、`market_scope.py`、`feishu_publish.py`、`publication.py` 和 `subscription.py`，消息和定时复用宿主现有官方能力。CLI/API 都可在批准范围内使用，不为本流程另建工具体系。

**能力边界：**现有 `geo_run.py` 是一次范围的取数与发布入口；`restrict_snapshot` 可裁剪国家，`scope_config` 可隔离发布状态，`subscription.configure` 仅保存私有订阅草稿。仓库没有常驻中央服务、多订阅合并执行器、自动投递器或原生调度器；这些须由获批宿主串联并实测。不能将保存草稿或一个国家本地生成成功称为全链路已部署。

## 先核对权限与环境

首次接入、换应用/身份/环境或连接变更时，先给用户一份「能力、已验证/待验证/缺失、证据时间、处理人、是否需企业审批、下一步」清单。预检只读，不自动登录、申请权限、发布应用版本或恢复任务；未验证不当作缺失。只检查配置存在不能标实读/发布/投递通过。

| 能力 | 最小要求与复用方式 |
|---|---|
| 持续运行 | 公司批准的持续在线主机/容器或 Agent 执行环境；能运行 Python 3.9+、SQLite 3.30+、requirements.txt 依赖和现有官方 CLI，能访问飞书与 Answerbit。不依赖个人电脑不休眠或临时聊天进程。 |
| 安全与状态 | Answerbit 与飞书凭证分开保管；持久私有目录保存同批题库、原文库、来源指纹、国家输出、订阅、候选/成功回执及投递记录。任务串行，具备超时、故障记录和恢复能力；不并行覆盖同一输出/状态。 |
| Answerbit | 管理员安全配置品牌级只读 Key 与私有资源，核验品牌及只读范围；运营查看/订阅不需要持有 Key。无人值守沿用获批有效凭证，失效停止并通知。 |
| 最新题库 | 复用指定题库只读连接及文件阅读权；Wiki 入口核对 `wiki:node:retrieve`，当前表格 CLI 路径核对 `sheets:spreadsheet:read`。只授予阅读，不要求编辑；开通后完整实读，按[题库连接](feishu-connection.md)区分应用权限、用户授权与资源访问。 |
| 飞书发布 | 按[现有最小发布权限表](feishu-preview.md#一次列清发布权限)核对上传、回读、成员与分享；同应用已有有效权限复用。常规查重使用中央记录和已知文件标识，无需目录枚举权限。首次/状态恢复由管理员核查历史，不为常规发布新增目录审批。 |
| 主动消息 | 应用机器人发送核对 `im:message:send_as_bot`，接收人在应用可用范围内；群投递还需机器人入群并可发言。已知获准接收标识时不为发消息索要全量通讯录。 |
| 接收订阅（按需） | 宿主没有现成对话能力而自行接消息事件时，私聊核对 `im:message.p2p_msg:readonly`，群 @ 核对 `im:message.group_at_msg:readonly`；不申请全群消息读取。已有宿主能力先复用，不重复搭建。 |
| 浏览器与账号 | 获准的真实飞书预览验收能力，以及实际运营账号的允许/拒绝范围验证；本地 HTML 测试不代替云端验证，窄屏浏览器不代替手机 App。长期自动发布须有可重复执行的验收通道；人工补发布不算自动化通过。 |
| 订阅与调度 | 管理员批准用户标识→国家/数据范围→接收位置的映射；宿主支持持久任务、时区、暂停、失败通知及投递去重。不存在可通用于所有宿主的“定时 scope”，按实际平台核对。 |

企业审批项在申请、扩权或发布权限版本前先报告：名称、用途、资源范围、现有权限不足的证据、审批要求和替代方式；等用户决定。免审不等于可自行新增权限。不同 Agent 复用同一获批应用不必机械重批，但每个运行环境须获准配置并实读，不复制个人令牌；另一应用的成功不能替代当前应用验收。

## 统一入口登记订阅

单次分析不强制订阅。当前已暂停的任务继续暂停，更新 Skill、修权限、补发布、登记订阅或单次验收成功都不能自动恢复；单次完整验收通过后，仍须用户另行明确要求启用/恢复，并回读任务状态。

1. **确认运营国家与授权。** 向运营确认负责国家（可多国），核对管理员批准的用户标识、允许国家和接收位置，本次已明确的不重复问。中央运行者安全提供或检查品牌级只读 Key，不要求订阅者在自己的 Agent 再提供 Key。获准范围与凭证未齐备前不真实取数或发布。
2. **询问推送需求。** 问：“需要定时推送吗？希望多久一次、哪天几点、发到哪里？推荐每周一北京时间上午11:30，汇总前七个完整自然日；也可自定义或仅做本次分析。”首次配置必须等用户回答；接受推荐但未另指定时间时，默认每周一11:30、Asia/Shanghai。未回复不自动建任务。已有订阅时展示当前设置，确认沿用或调整，不擅自将自定义时间改成默认值。用户已明确频率、时间和接收位置时直接采用。未指定时区默认北京时间并告知；其他时区需按用户要求保存，并说明夏令时影响。
3. **按身份准备内容。** 仅纳入确认国家，范围内平台、分组、标签默认全部，用户指定时按交集筛选。按范围重算指标、结论和行动，多国分别展示。HTML内嵌数据、筛选可选项、题单、简报和附件均裁剪到该范围，不能只预选国家而交付全量数据。无法裁剪时停止共享。国家自报不代替公司权限。
4. **检查能力并保存待验收配置。** 按上表核对中央环境、统一入口、验收和投递能力。复用稳定订阅及任务 ID，先查重，不接管他人任务。缺能力时保存待接入/待验证配置并列清缺项，不声称已后台运行。任何订阅变更都不隐含启用调度；已有任务仍暂停，待验收阶段不新建启用的周期任务。
5. **验收通过后等待启用指令。** 先按下节手动完成一次全链路验收。通过后报告“单次已验收，定时仍暂停”，列出剩余调度验证及启用条件。只有用户明确要求后才用宿主原生工具调整原任务，回读频率、时间、时区、窗口、接收位置、任务 ID、状态和下一次执行时间；实际触发与目标送达仍须验证，不能凭创建成功称已验收。用户调整频率、国家或暂停时更新同一任务，重验受影响部分。

## 中央单次运行与验收

1. **锁定获准请求。** 明确本次品牌、窗口、题库、指标版本、国家集合和接收人；同一品牌/窗口/题库及口径的兼容请求串行合并。平台、分组或标签范围不同且无法证明可从完整母批准确重算时分批，不复用缺字段或不完整母批。中央读取全品牌须在公司批准范围内，母批仅留私有环境。
2. **先验连接与能力。** 按题库连接和发布权限表实读诊断，一次列清缺项；检查对应范围的中央登记已初始化或完整迁移，再取真实数据。`geo_run.py --check` 只检查本机配置，`feishu_publish.py --check-access` 只探测成员和分享读取能力，都不是完整验收。记录缺失/损坏时管理员先核对历史并恢复，不将目录扫描或重新取数作为自动补救。发布已知不可用时先报告，只有用户仍要求本地分析才继续对应工作，不能预计发布必败却将本地附件当完成。
3. **在线题库通过后才取数。** 用现有刷新流程实读最新题库、核对完整国家页/修订/题号，再读取 Answerbit 已有回答，完成分页闭合、题号匹配、原文质量检查和推荐判断。同批兼容范围只取一次；不得逐订阅重复 refresh。题库或取数失败停止，不回退旧库冒充成功。
4. **从母批生成国家交付。** 复用 `market_scope.restrict_snapshot`、现有计算/模板/Excel/简报及 `scope_config`，使用独立目标副本，不能原地裁剪唯一母批。每份保留母批来源、同批题库内容校验值、线上读取修订与时间、指标版本及国家范围；数据库、HTML、Excel、报告与发布 manifest 必须对应。纯离线派生不另读平台、原文或最新题库，也不改写母批；离线重绘若丢失线上题库来源回执，不得填造 `feishu-live`，须由宿主适配并验证来源传递后再发布。现有 `geo_run.py` 可先验收一个已批准国家组合，不代表多订阅分发已自动接通。
5. **生成及上传前自检。** 核对有效样本、去重、分子分母、负面扣除、未知/零分母、历史可比条件与证据行动；检查各国副本的内嵌数据、题单、筛选选项和上次对比均无范围外记录。共享件不含回答原文、原文数据库、凭证和本机地址。Excel 默认留本地；订阅国家只作偏好，文件权限仍需独立验证。
6. **查重、发布和真实预览。** 使用既有强版本查重；相同且仍可访问的已验收版本复用，变化后生成候选。按飞书交付规程回读文件、核对分享与成员、实测多选/矩阵/页面/对照/图表/分页/指标说明以及桌面和手机边界。只有验收通过才登记成功入口。新模板或功能变化后不能复用旧截图作本次交互通过证据。
7. **核对目标投递。** 仅向本次批准的目标发同批简报和已验收预览链接；验证真实接收人可打开、交互及数据范围，不能以管理员账号代替。记录版本、范围、接收标识、消息 ID/时间及投递状态；消息成功不等于看板访问成功。统一 Agent 与执行环境的身份不同时须分别核对，不借另一个机器人冒充统一入口。
8. **保留暂停并交接。** 报告各环节实际证据、未通过项、上一成功入口和下一步；手动跑通后仍保持定时暂停。用合成故障或隔离测试核对无变化去重、失败保留旧版和异常通知，不为测故障制造真实平台扣费或改权限。原生定时触发须在用户另行批准的受控测试中验收，不能把手动成功写成定时已验证。

发布失败只重试现有已校验批次的 `feishu_publish.py`，不再次调用 refresh、重读题库或 Answerbit。单个国家派生/发布失败不能标该国成功或发送他国替代结果；其他独立范围仅在各自完整验收且已获准时交付。通知失败保留待补发记录，不重复取数；补发前核对链接仍可访问。

## 私有订阅状态

仅存获批私有环境，不提交公开仓库。安全凭证只保留引用，不记录密钥明文。下面仅为待配置结构示例，不代表任务已创建：

```json
{
  "subscription_id": "private_stable_subscription_id",
  "owner": "verified_current_operator",
  "timezone": "Asia/Shanghai",
  "frequency": "weekly",
  "weekdays": ["MO"],
  "local_time": "11:30",
  "window": "previous_7_complete_days",
  "schedule_confirmed": false,
  "status": "waiting_for_confirmation",
  "routes": [{"markets": [], "recipient": "verified_recipient", "destination": "verified_agent_conversation", "verified": false}],
  "scheduler_job_id": null,
  "last_success_by_scope": {}
}
```

国家和接收者须确认，不能按语言、IP、采样地区或同名联系人猜。接收路由与文件共享范围必须一致，不自动扩大权限。无人值守任务沿用已确认国家和安全凭证，不每次索取Key；凭证失效或权限变化则停止并通知。

私有配置可复用仓库`subscription.configure`：用户确认后保存运营国家、频率、日期时间、时区和接收位置，复用subscription_id与原scheduler_job_id，文件权限为仅当前用户读写。修改后回到待验证，未确认不落盘；只保存草稿，不会创建后台任务，也不保存Key。原生调度器的创建、暂停或更新时间仍须由运行Agent实际执行并回读验证，不能把保存草稿说成已启用。

## 每次定时运行

- 按已确认计划检查已有采样，不创建或修改 Answerbit 采样任务。默认取触发日D的D-7至D-1七个完整北京时间自然日；默认周一执行对应上一周周一至周日。自定义频率不自动改变数据窗口，需在回执说明；其他时区的触发时间不改变数据窗口口径，除非用户明确要求。
- 读取最新获批题库与已有回答，完整对账并唯一匹配题号，沿用现有指标定义。提及率仍为未点名题、扣除明确负面，推荐注明本地规则初判。
- 对各范围核对上次成功版本：窗口、品牌、题库、范围、样本集合、指标口径与关键回答/判定、来源、口碑和状态校验值。不能仅凭条数或样本ID判无变化。历史证据不足时说明，不能伪造基线。
- 无变化时默认静默，用户要求固定周期也收状态简报时按其确认设置执行。有变化且数据、权限与预览全部验收通过后，发送已验收看板和同批简报；无法验收时通知待验收，不预填通过。
- 失败不发布半批、不覆盖上一成功版本。异常通知指出国家/窗口、失败环节、原因、影响、上一成功入口和时间，以及到Answerbit、飞书题库或权限管理核实的位置；没有旧版时明说。渠道本身失败时记录并使用预先批准的备用渠道，没有备用渠道则说明无法保证通知。
- 按接收者、范围和验收版本记录投递，已送达者不重复发送，补发只针对失败者。私有状态不含回答原文或密钥。回答原文和原文库不推送，Excel默认留本地。

## 通知内容

沿用[Skill简短报告](../SKILL.md#简短报告与上次对比)，范围限于订阅国家。运行条件不足时明确限制，不承诺任意Agent安装后即可推送。

## 验收场景

| 用户需求或状态 | 预期行为 |
|---|---|
| 接受推荐 | 保存每周一11:30、Asia/Shanghai 的待验收订阅，不自动启用 |
| 每周三下午3点 | 按周三15:00设置，不沿用默认周一 |
| 已有自定义订阅，再次运行 | 展示设置并确认沿用或修改，更新原任务，不重复创建 |
| 未回复是否定时或时间 | 等待确认，不自动启用 |
| 仅单次分析 | 不创建订阅 |
| Key齐备但国家未确认 | 不真实取数、不默认发全量 |
| 缺连接器、发布或接收验证 | 保留待接入/验证，不启用、不发送假报告 |
| 异常或上传中断 | 保留上一成功入口，按已验证渠道通知 |
| 两个国家同品牌、窗口、题库和口径，中央母批完整 | 一次取数，独立裁剪/重算/验收；不按国家重复 refresh |
| 母批缺必要字段、来源回执或题号歧义 | 不猜值、不伪造来源，不发布对应范围 |
| 某国看板内嵌其他国家或整批历史 | 阻止共享，不能仅预选国家掩盖泄漏 |
| 单次全链路通过，未收到恢复指令 | 报告单次通过，原定时任务仍暂停 |
| 统一入口可聊天，但中央执行或投递未接通 | 标待接入，不承诺已定时运行 |
