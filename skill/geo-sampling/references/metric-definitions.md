# GEO 指标定义

## 当前默认提及率

分析口径版本 `geo-core/4-answer-quality`，展示名称统一为「提及率」。

| 看什么 | 怎么算 | 注意什么 |
| --- | --- | --- |
| 未被题目点名时的品牌可见度 | 未点名题中正文提及 Kalodata、且平台口碑未判为明确负面的有效回答数 ÷ 未点名题有效回答数 | 同一任务最多计一次，负面回答留在分母，褒贬并存和口碑未知的正文命中仍在分子。零分母不适用。 |
| 题文是否点名 | 检查 Answerbit 返回题文中的 Kalodata、Kalo Data、Kalo-Data、カロデータ及审核过的全半角等价写法 | 从返回题文判定，与正文命中分开；题库编号继续用于定位。旧批缺少返回题文时按唯一匹配题库回算并注明来源，历史对比提示限制。 |
| 点名题结果 | 在点名题内部独立统计提及、推荐及口碑 | 不进入默认提及率，首页有独立专题。 |
| 平台原值 | Answerbit 平台快照提及率原样显示 | 标明「平台口径」。竞品提及率按全部正文命中，和 Kalodata 扣除明确负面的提及率存在差异。 |

正文先排除 URL 和开头原样复述的题文，再按审核别名识别，保留标题、列表、表格顺序。新批次的 `sample_question` 保存逐条返回题文及点名状态，`sample_content` 保存正文判定和原始口碑码。Excel 用「点名状态」及「提及率分子」列核对，标为「计入」的条数是分子，未点名且有效的记录数是分母。

手算例。4 条未点名有效回答分别为明确负面提及、褒贬并存提及、口碑未知提及和未提及，分子为 2、分母为 4、扣除负面为 1，提及率 50%。另有英文或日文点名题时单独展示，不改变这 4 条的分母。

## 回答原文质量检查

快照版本 `answerbit-observed/5-quality`，筛查规则 `answer-quality/2`。先核对题号与列表/详情一致性，再检查原文；不能仅凭平台状态“分析完成”就当有效回答。

| 看什么 | 怎么算 | 注意什么 |
| --- | --- | --- |
| 无效原文 | 空白、仅复述题文、短的纯报错/采集失败文本、纯拒答、明确回答截断标记，标“数据异常” | 仅含错误信息的 JSON 错误封套也排除；带有效数据或分析字段的 JSON 不按错误封套排除。拒答覆盖中、英、日、韩、德、法、越、泰、印尼、马来语的已测试写法，整段匹配；后续有有效内容时不因拒答前缀排除。规则不能保证覆盖所有写法。 |
| 长度待核查 | 按同题号、相同返回题文、平台、语言、地区及已知终端/回答模式在本批分组。2 条用较长回答；3 条及以上用接近中位长度的回答。参考至少 200 文本单位，当前不超过参考的 35% 且减少至少 150 单位，标记长度变化 | 仅长度变化仍纳入统计，在看板与 Excel 单列“长度待核查”，不等于数据异常；完整短回答保留。单位按中日韩泰字符逐字、其余连续词计，阈值不是业务质量标准。无同条件参考不凭短排除。 |
| 疑似缩水 | 长度条件成立，且题文明示的至少两项要求在当前正文均未检出，同组参考回答具备对应信号，才标“数据异常：疑似缩水”并排除 | 首版仅识别中英文明确要求的“限制说明”和“来源链接”：正文用估算、限制、核验等措辞与 HTTP(S)/www 链接核对。优先用同组具备这些信号的较长回答作参考，避免多数不完整短回答成为参考。题文包含否定要求、未覆盖语言/要求、仅缺一项或参考也缺项时，不擅自判缺失，仅提示长度待核查。这是可回查的规则初判，不能证明平台截断或完整理解所有语义。 |
| 指标影响 | 无效与有缺项证据的疑似缩水从全部 Skill 自算指标的分子和分母排除，不当作未提及；仅长度待核查仍纳入。正常的明确负面仍仅从提及率分子扣除 | 先质量筛查再做提及、顺位、口碑、推荐、引用。平台原生快照保持原值，未套用此过滤。新旧质量口径不直接计算差值。 |
| 回查与留痕 | `sample_quality` 保存原因、长度、参考任务及当时的规则版本；原文保留获批本机，异常题号与正常记录共用真实匹配结果 | 看板“回答表现→原文质量”及同批 Excel“回答质量”均可查，明确区分“已排除”与“仍纳入”。共享HTML不含原文；工作台仅是查找入口。本地查询可查异常和参考原文。旧批按实际保存版本展示，不伪装新版；未检查显示“需刷新”。 |

手算例：题目明确要求限制说明及来源链接，同题同模型一条 300 单位回答具备这两项，一条 30 单位回答两项均缺，再加一条纯报错。后两条单列数据异常，有效样本为 1；若长回答未点名题中提及 Kalodata 且非明确负面，提及率为 1/1。若 30 单位回答具备对应信号，或题目未明确要求这两项，则保留统计并提示长度待核查；若其正文也提及品牌且非明确负面，提及率为 2/2。没有同条件参考时不因短排除。整批排除后没有有效回答时停止刷新，保留上一成功结果。

上次测量比较须同时核对题库版本、匹配题目及返回题目范围、分析口径、平台、语言、分组、标签和窗口长度。范围或口径缺失、不同都只并列显示，不计算变化。自动上次比较仍为两批整批范围，顶部筛选改变时单独提示。平台原值与 Skill 自算值分别列来源及时间窗。

以下内容保留合成试跑和历史指标的定义，默认简报及首页采用本节口径。

口径版本 `geo-demo/1`。每个采样单元是题号、语言、平台和轮次的组合。按启用题单计计划分母。完全相同的重复记录仅计一次；相同单元有不同记录 ID 时先人工核对。失败与缺样单列。汇总先合计分子、分母再计算比例。

| 指标 | 分子 | 分母 |
|---|---|---|
| 有效覆盖率 | 窗口内有效回答单元 | 实际计划单元 |
| Kalodata 提及率 | 正文命中 Kalodata 或 Kalo Data 的有效回答单元，正文 URL 不计 | 有效回答单元 |
| 官网引用率 | 正式来源命中 kalodata.com 或其子域的有效回答单元 | 正式来源可判定的有效回答单元 |
| 引用字段覆盖率 | 正式来源可判定的有效回答单元 | 有效回答单元 |

明确无引用属于可判定，字段缺失或格式无效属于未知。点名与未点名题分别比较。零分母显示不适用。官网域名命中不验证引用是否支撑回答中的具体说法。

合成样例有 5 个计划单元、3 条有效回答、1 条失败、1 个缺样。2 条有效回答提及品牌，1 条引用官网，另有 1 条引用字段未知。因此覆盖率 3/5、提及率 2/3、官网引用率 1/2、引用字段覆盖率 2/3。一次重复拉取不增加分母。

`answerbit-observed/1` 使用 Answerbit 任务 ID 去重，保留各条任务的实际日期。仅纳入唯一匹配题库、且状态已完成并有有效正文的回答；其他状态及题号歧义单列。提及与引用沿用上表定义，分母仅限本次读取并匹配的有效记录。该模式只读取回答记录，采样覆盖率留空，不能据此宣布首轮基线已完成。

`answerbit-observed/2` 将日文品牌名「カロデータ」（含半角等价写法）纳入提及率，并记录题目和回答的品牌写法。按题目写法区分拉丁字母（`latin`）、日文（`ja`）、两者（`both`）和未点名（`none`）。回答中的两种写法同时出现时，总提及仍计一次，写法明细各计一次。回答未确认时写法未知。旧版 `answerbit-observed/1` 的写法明细显示未知，品牌提及率与新版分别比较。

## 第 18 行品牌官网链接

| 指标 | 分子 | 分母 |
|---|---|---|
| 正文官网链接出现率 | 正文含该品牌官网 URL 或裸域名的有效回答数 | 全部有效回答数 |
| 正式来源官网命中率 | Answerbit 的正式来源含该品牌官网的有效回答数 | 正式来源可判定的有效回答数 |
| 正式来源字段覆盖率 | 正式来源可判定的有效回答数 | 全部有效回答数 |

Kalodata（kalodata.com）和 FastMoss（fastmoss.com）分开计算，包含各自子域。每个回答对同一品牌、同一口径只计一次，两项可同时命中。正式来源明确为空计为可判定无命中；缺失或无法解析计为未知。默认算总体，按用户要求筛选或拆分 Answerbit 分组、标签，各范围单独计算分子和分母。多标签样本可出现在多个切片里，总体仍只计一次。快照只保存命中判定，旧快照需刷新后才能获得完整结果。

## 内容指标 answerbit-observed/3

有效回答与旧版沿用同一资格判定。第 2、3、4、5、7、8 行从回答正文计算，去除 URL、裸域名和开头原样复述的题文，保留标题、列表、表格的阅读顺序。按唯一任务 ID 汇总。新版变更提及口径，趋势使用相同版本重算。

| 行 | 指标 | 计算 |
| --- | --- | --- |
| 2 | 各品牌提及率 | 命中该品牌的有效回答数 ÷ 有效回答数。Kalodata 分子排除平台口碑码为 2 的负面提及；竞品按全部正文命中计。每个品牌在同一回答最多计一次。 |
| 3 | 多品牌提及份额 | 该品牌的提及回答数 ÷ 同范围配置品牌各自提及回答数之和。无品牌命中时不适用。 |
| 4 | Kalodata 首次出现第一比例 | Kalodata 最先出现的回答数 ÷ 全部有效回答数。 |
| 5 | Kalodata 平均首次出现名次 | Kalodata 的名次总和 ÷ 有 Kalodata 名次的回答数。 |
| 7 | 按主题、问题和平台拆分 | 使用 Answerbit 分组为主题。按市场和点名状态保留分母，可进一步按分组、题号、平台、标签或分组与平台组合重算第 2 至 5 行。 |
| 8 | Kalodata 推荐 | 明确、条件、中立分别用对应回答数 ÷ 全部有效回答数。判定规则见下。 |
| 10 | Kalodata 平台情感 | 未提及、正面、负面、褒贬并存、中性、未知分别计数。全样本分布以全部有效回答为分母。仅看已提及时，以口碑码 1–4 的回答数为分母。 |
| 18 | 官网链接 | 沿用上节定义，独立计算正文官网链接与正式来源。 |

各市场配置含 Kalodata。美国竞品为 FastMoss、EchoTik、Winning Hunter。日本为 FastMoss、EchoTik、Astream Deep、Exolyt、TikTok Studio、Modash、Upfluence。中国和韩国为 FastMoss、EchoTik、出海匠。其他市场为 FastMoss、EchoTik。Kalodata 同时识别 Kalo Data 和「カロデータ」，含等价全角及半角写法。不同配置市场的份额分别报告。点名状态优先按 Answerbit 返回的逐条题文判定，旧批回算注明来源。

推荐采用本地保守初判。中文、英文、日文的明确措辞按同一语句内的对象和条件判定。直接建议为明确；附明确适用条件为条件；两类都在同一回答中成立时仅归中立。不提及品牌或明确否定且无正向推荐时计未推荐；纯列举、无识别规则语言、转述、竞品共句、否定或指代不清等保守记未知，均不进入三类分子。三类互斥，未知计入总分母，报告应列可判定覆盖率与复核状态。中立题单仅保留提问与逐条回查定位。

平台情感只评价当前查询品牌 Kalodata。详情字段 `brand_reputation` 的取值为 0 未提及、1 正面、2 负面、3 褒贬并存、4 中性。缺失、非整数或未知枚举记为未知。读取快照时按原始口碑码映射，已保存原始码的快照可直接重算。平台的未提及状态与本地正文提及判定分别统计。

默认提及率按本节开头的未点名题口径计算，全部题型结果仅作补充。负面回答保留在分母，褒贬并存和口碑未知的正文命中仍计入分子。提及份额、首次出现位置及 Answerbit 平台快照各用自己的原口径。历史快照没有逐条口碑时，查询标记为 `all_mentions_legacy`，按历史全提及口径展示。

合成例：同市场三条有效回答，第一条先 FastMoss 后 Kalodata 且平台判为负面，第二条只提及 Kalodata，第三条均未提及。Kalodata 提及率 1/3、份额 2/3、首次第一比例 1/3、平均首次名次 (2+1)/2。若第一条同时向不同情境给出直接建议与条件建议，则中立推荐率 1/3。

## 场景应用

按[运营场景与指标](analysis-scenarios.md)选择优先指标。场景不修改指标公式；分组、标签和实际题文状态分别保留。

## 国家与题类矩阵和口碑构成

矩阵以实际国家及 Answerbit 分组或标签独立交叉分组，仅用题文未点名 Kalodata 的有效回答，格内沿用提及率公式。标签可能重叠，维度来源明确标注；空分母不适用，缺失元数据不推定为任何题类。跨格题库、平台及样本构成不一定相同，颜色不建立因果或排名。未设定固定业务样本阈值，最小非空样本量仅作相对提示。

首页平台口碑六类互斥：正面、中性、负面、褒贬并存、未提及、未知。各类计数 ÷ 全部有效回答；可识别字段覆盖率 =（全部有效回答 − 未知）÷ 全部有效回答。未知存在时覆盖率不得为 100%，零分母不绘制构成图。负面和褒贬并存分别展示计数和占比，合计指标为两类计数之和 ÷ 同一分母，不解释为推荐判断。
