# 飞书内预览交付

## 生成与上传

先按正常流程取得当前运行者的 Answerbit 品牌级只读 Key，完成整批取数、题号匹配和校验。不要因有旧共享文件而跳过真实运行的凭证门槛。用户明确要求历史预览验收时可使用已有成功批次，注明非实时刷新。

从仓库根目录执行：

```sh
python3 feishu_delivery.py /private/path/GEO运营看板.html /private/path/飞书GEO看板.html
```

共享文件保留汇总、题文和定位字段；不携带回答正文、本机查询地址和 SQLite。程序拒绝未审核顶层字段、已知原文/凭证字段和疑似密钥，来源旁有失败状态文件时停止，已有共享文件不变。该校验不是任意恶意文本的脱敏保证，新增字段先检查内容和共享范围。

飞书使用独立授权。公司批准的文件夹和管理员名单保存在私有运行配置，不写公开仓库。使用已安装的官方 CLI 或获授权的网页上传，不自建文件托管：

```sh
lark-cli drive +upload --file /private/path/飞书GEO看板.html --folder-token "$GEO_FEISHU_FOLDER_TOKEN" --as bot
```

仅申请实际必需的上传、元数据读取、文件权限设置读取/收紧和成员读取权限，限定应用可访问的目标目录。CLI 缺权限时停止自动发布并报告具体环节；不能为绕过错误而申请完整 Drive 权限。CLI 新建文件可能自动授予当前 CLI 用户管理权，须确认该用户在批准管理员名单中。不要转移所有权。

## 发布门槛

1. 新版先独立上传验收，保留上一份成功入口；上传成功不等于发布成功。
2. **逐个检查新文件权限**，不能假设继承文件夹的链接分享设置。首次验收关闭链接分享，只允许批准的管理员；核对继承与直接协作者。发现默认组织内链接可读时立即收紧，不发给运营。
3. 在飞书实际预览测试市场、平台、日期、分组、标签筛选，矩阵点击、分页、对照、指标说明及图表。共享模式已对 srcdoc 内片段导航作兼容处理。预览服务返回 READY 不能代替交互测试。
4. 测试桌面和窄屏；窄屏浏览器不代替飞书手机端验收。用真实运营账号验证访问与禁止范围；未验证前仍保持管理员试点。
5. 校验和权限验收通过后才返回新入口。失败时返回上一份已验收入口（若有），明确失败阶段、最后成功时间及数据窗口，不宣称新结果已发布。

## 原文与运行结果

飞书共享版不连接本机原文数据库，不提供 localhost 链接。到 Answerbit 工作台的大模型回答记录，按表内题文、日期、平台和分组定位，题号用于飞书题库。工作台入口不是原文直达链接。含原文 SQLite 不上传飞书或 GitHub；Excel 不随本流程自动上传。

交付简短报告及实际飞书预览入口，注明批次、更新时间、手动/自动更新方式、实际交互测试结果、权限与真实账号测试状态、原文回查方式及阻塞。

## 后续自动更新设计（未启用）

在公司批准的常驻运行环境手动或定时调用现有刷新与共享准备流程；建议先每个工作日一次，频率由负责人确定。Answerbit 和飞书凭证分别放环境密钥库，不存定时任务文本。每次新文件验证通过才切换私有最新成功索引；失败不替换入口，运行报告列失败阶段。尚未实现定时任务、远端自动权限验收或自动入口切换时，必须写“手动更新”，不得写“实时自动发布”。
